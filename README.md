# ربات ترید طلا 🟡

ربات معامله‌گر **طلا** به زبان پایتون، با **پنل وب فارسی**، موتور بک‌تست و
معامله کاغذی (پول تقلبی). برای برنامه‌نویسی که اقتصاد نخوانده ساخته شده:
هر عدد و هر تصمیم ربات در پنل به زبان ساده توضیح داده می‌شود.

> ⚠️ **این ربات سود تضمینی ندارد و عمداً فقط با پول تقلبی کار می‌کند.**
> ابزاری است برای اندازه‌گیری: اول روی گذشته تست کن (بک‌تست)، بعد چند ماه
> با قیمت واقعی و پول تقلبی اجرا کن، و فقط اگر هر دو قانع‌کننده بود به
> پول واقعی فکر کن.

---

## چه چیزهایی دارد؟

| بخش | کار |
|---|---|
| **داشبورد** | قیمت زنده طلا، نمودار کندلی با خطوط استراتژی و نقاط خرید/فروش، وضعیت حساب، پوزیشن باز با حد ضرر و سود، منحنی سرمایه، گزارش لحظه‌ای |
| **«ربات الان چه فکر می‌کند؟»** | شرط‌های استراتژی با ✓ و ✕ به فارسی ساده؛ مثلاً «روند کلی صعودی است» یا «منتظر عبور میانگین به بالا» |
| **بک‌تست** | اجرای هر استراتژی روی گذشته + **قضاوت ساده** (خوب/متوسط/ضعیف و چرا)، مقایسه با «خرید و نگه‌داری»، تست جداگانه روی دو نیمه داده |
| **تنظیمات** | انتخاب نماد، منبع قیمت، استراتژی و پارامترها، مدیریت ریسک با مثال عددی — همه با توضیح |
| **راهنما** | واژه‌نامه (کندل، ATR، حد ضرر، افت سرمایه، ...) و مسیر پیشنهادی شروع |
| **امنیت** | رمز عبور، قفل IP بعد از ۵ تلاش ناموفق، کوکی امن، هدرهای امنیتی، پنل پیش‌فرض فقط روی 127.0.0.1 |
| **پایداری** | سرویس systemd؛ بعد از ری‌استارت سرور، ربات خودکار دوباره روشن می‌شود و وضعیت حساب حفظ می‌شود |

همه فایل‌های پنل (کتابخانه نمودار و فونت وزیرمتن) داخل پروژه‌اند؛ به هیچ
CDN خارجی وابسته نیست، پس روی سرور داخل ایران هم کامل کار می‌کند.

## قیمت طلا از کجا می‌آید؟

نماد پیش‌فرض `XAUUSD` است (یک اونس طلا به دلار). هر منبع خودش آن را به
نماد درست ترجمه می‌کند و منبع `auto` به ترتیب امتحانشان می‌کند:

| منبع | نماد طلا | از کجا کار می‌کند |
|---|---|---|
| **nobitex** | `PAXGUSDT` (پکس‌گلد) | سرور داخل ایران |
| **binance** | `PAXGUSDT` | سرور خارج از ایران |
| **yahoo** | `GC=F` (قرارداد آتی طلا) | سرور خارج از ایران |
| **sample** | داده مصنوعی | همه‌جا، بدون اینترنت — فقط برای آشنایی |

**PAXG** توکنی است که پشتوانه هر واحدش یک اونس طلای واقعی است؛ قیمتش
تقریباً همان قیمت جهانی طلاست و ۲۴ ساعته معامله می‌شود. برای قیمت ریالی
نماد `PAXGIRT` از نوبیتکس را انتخاب کن.

در پنل: **تنظیمات ← «بررسی دسترسی سرور به منابع قیمت»** نشان می‌دهد
سرورت به کدام منبع دسترسی دارد.

## نصب روی سرور (Ubuntu 24.04) — پیشنهادی

سرور ۲ هسته / ۴ گیگ کاملاً کافی است (پنل و ربات روی هم حدود ۱۰۰ تا ۲۰۰ مگابایت رم مصرف می‌کنند).

```bash
# ۱) روی سرور، پروژه را بگیر
git clone https://github.com/alifard1402/My_Traid_prg.git
cd My_Traid_prg

# ۲) نصب با یک دستور
sudo bash deploy/install.sh
```

اسکریپت همه کارها را می‌کند: پایتون، محیط مجازی، ساخت رمز تصادفی برای
پنل، و سرویس `goldbot` که ۲۴ ساعته روشن می‌ماند. در آخر **رمز پنل** و
دستور اتصال را چاپ می‌کند.

### باز کردن پنل (روش امن: تونل SSH)

پنل فقط روی خود سرور گوش می‌دهد و از اینترنت مستقیم دیده نمی‌شود. روی
**کامپیوتر خودت** (نه سرور) بزن:

```bash
ssh -L 8000:127.0.0.1:8000 USER@SERVER_IP
```

تا وقتی این ترمینال باز است، در مرورگر برو به **http://localhost:8000**.
(در ویندوز ۱۰/۱۱ همین دستور در PowerShell کار می‌کند.)

### دسترسی مستقیم با دامنه و HTTPS (اختیاری)

اگر دامنه داری و می‌خواهی از موبایل هم بدون تونل وارد شوی، راهنمای کامل
در `deploy/nginx-goldbot.conf` است (nginx + گواهی رایگان certbot + فایروال).
**پنل را بدون HTTPS روی اینترنت باز نکن** — رمزت رمزنگاری‌نشده رد و بدل می‌شود.

### دستورهای مفید روی سرور

```bash
sudo systemctl status goldbot      # وضعیت سرویس
sudo systemctl restart goldbot     # ری‌استارت
sudo journalctl -u goldbot -f      # گزارش زنده
sudo bash deploy/update.sh         # به‌روزرسانی از گیت‌هاب (حساب و تنظیمات حفظ می‌شود)
cat .env                           # دیدن رمز پنل
```

برای عوض کردن رمز: `PANEL_PASSWORD` را در فایل `.env` عوض کن و سرویس را ری‌استارت کن.

## مسیر پیشنهادی (خیلی مهم)

```
۱. تنظیمات ← «بررسی دسترسی»        ببین سرورت کدام منبع قیمت را می‌بیند
۲. بک‌تست                          هر سه استراتژی را روی ۲۰۰۰ تا ۳۰۰۰ کندل امتحان کن
۳. «استفاده از این تنظیمات»       بهترین را برای ربات انتخاب کن
۴. داشبورد ← «روشن کن»             ربات با پول تقلبی معامله می‌کند
۵. ۱ تا ۳ ماه صبر                  نتیجه کاغذی را با بک‌تست مقایسه کن
۶. فقط اگر مرحله ۵ قانع‌کننده بود: با کمترین مبلغ ممکن به پول واقعی فکر کن
```

**از مرحله ۵ نپر.** فرق نتیجه کاغذی با بک‌تست، تنها چیزی است که می‌گوید
بک‌تستت دروغ می‌گفته یا نه.

## سه استراتژی داخل ربات

| استراتژی | منطق به زبان ساده | ویژگی |
|---|---|---|
| **دنبال‌کردن روند** (`ema_trend`) | وقتی روند کلی صعودی است و میانگین کوتاه‌مدت از میانگین میان‌مدت بالا می‌زند، بخر. وقتی برگشت پایین، بفروش. | ساده و کلاسیک؛ نقطه شروع خوب |
| **شکست سقف** (`donchian_breakout`) | وقتی قیمت سقف چند هفته اخیر را شکست، بخر. وقتی کف کانال را شکست، بفروش. | درصد برد پایین، ولی سود بزرگ در روندهای قوی |
| **خرید در اصلاح** (`rsi_pullback`) | در روند صعودی، وقتی قیمت موقتاً زیادی افت کرد و برگشت، بخر. | درصد برد بالاتر، سود هر معامله کمتر |

همه آن‌ها حد ضرر و حد سود را بر اساس **ATR** (میانگین اندازه حرکت قیمت)
می‌گذارند و حجم معامله را **مدیریت ریسک** تعیین می‌کند:

```
حجم معامله = (سرمایه × ۱٪) ÷ فاصله حد ضرر
```

یعنی اگر حد ضرر بخورد، دقیقاً ۱٪ سرمایه از دست می‌رود — نه بیشتر. با این
فرمول، ۱۰ باخت پشت‌سرهم فقط حدود ۱۰٪ حساب را می‌برد. اگر افت حساب از حد
مجاز (پیش‌فرض ۲۵٪) بیشتر شود، **کلید قطع اضطراری** همه‌چیز را می‌فروشد و
ربات را خاموش می‌کند.

## تله‌هایی که باید بشناسی

1. **نگاه به آینده:** اگر ربات هنگام تصمیم، از قیمت بسته شدن کندلی استفاده کند که هنوز تمام نشده، بک‌تست دروغ می‌گوید. این پروژه سیگنال هر کندل را روی قیمت باز شدن کندل *بعد* اجرا می‌کند و برای هر استراتژی تست دارد.
2. **بیش‌برازش:** پارامترهایی که فقط روی همان داده گذشته خوب‌اند. بک‌تست پنل داده را دو نیمه می‌کند و اگر فقط در یکی سود داشت، هشدار می‌دهد.
3. **کارمزد:** استراتژی‌ای که بدون کارمزد سود می‌دهد، با کارمزد ممکن است ضرر بدهد. کارمزد صرافی خودت را در تنظیمات بگذار.
4. **قیمت ایران ≠ قیمت جهانی:** قیمت طلای ۱۸ عیار در ایران به دلار آزاد هم بستگی دارد. این ربات قیمت جهانی (دلار/اونس) را معامله می‌کند.

## امنیت

- 🔒 فایل `.env` (رمز پنل) **هرگز** کامیت نمی‌شود.
- 🔒 پنل پیش‌فرض فقط روی `127.0.0.1` است؛ با تونل SSH یا nginx+HTTPS وصل شو.
- 🔒 اگر روزی حالت واقعی اضافه کردی: کلید API **بدون دسترسی برداشت**، IP سرور در لیست مجاز صرافی، و کمترین مبلغ ممکن.
